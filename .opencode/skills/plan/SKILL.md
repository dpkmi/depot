---
name: plan
description: Technical planning and architecture design for features. Produces implementation plans with risk assessment, affected systems, and ticket breakdown suggestions. Invoke when the user needs to plan, design, or architect a feature.
compatibility: opencode
---

## When to Use
- Feature requests needing technical analysis
- Architecture decisions
- Impact analysis across teams (Core, Angular, React Native)
- "How should we build this?" questions

## Steps
1. Read the full requirement
2. Identify affected teams and systems
3. Analyze existing codebase for relevant patterns
4. Produce implementation plan with steps, risks, and acceptance criteria
5. Suggest ticket breakdown for scrum master

## Output Structure
- Overview, affected systems, technical approach (step-by-step)
- Dependencies, risks & mitigations, acceptance criteria
- Estimated ticket breakdown
