## When to Use
- Design decisions, wireframes, mockups
- Design system or style guide creation
- Accessibility review of UI
- New screens or major UI changes
- Design inspiration or best practice research

## Web Research
Search for: platform guidelines (HIG, Material Design, Windows UI), industry patterns, WCAG 2.2, component library references (Tailwind UI, Radix, shadcn/ui)

## Platform Guidelines
- **WinForms:** Dense layouts, keyboard shortcuts, system colors, Segoe UI
- **Angular:** Tailwind tokens, responsive mobile-first, dark mode, 4px spacing base
- **React Native:** 44pt touch targets, bottom nav, platform fonts, safe areas, haptics

## Output
Design tokens (hex, px values), wireframes, component specs, interaction patterns, accessibility notes, and developer handoff instructions per platform.
